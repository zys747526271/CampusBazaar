# 02 · 本地运行与验收

## 2. 三种启动方式

### 2.1 只跑后端（最快，自带演示数据）

```bash
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
python -m backend.dev
```

`backend/dev.py` 依次完成：

1. 加载 `CAMPUS_CONFIG`（默认 `local`）；
2. 执行 `alembic upgrade head`（首次自动建表）；
3. `SEED_DEMO_DATA=true` 时幂等灌入演示数据与占位图；
4. 打印演示账号、验证码台账地址；
5. 启动 5000 端口与后台定时任务。

### 2.2 前后端分离开发

```bash
# 终端 1
python -m backend.dev --no-seed        # 已有数据时跳过种子，启动更快

# 终端 2
cd frontend
npm install
npm run dev                            # 8080，代理 /api 与 /static 到 5000
```

### 2.3 单命令演示（答辩/验收推荐）

```bash
cd frontend && npm run build && cd ..
python -m backend.dev --serve-dist
# 浏览器打开 http://127.0.0.1:5000 ，一个端口同时提供页面与接口
```

### 2.4 手机 / 局域网联调

手机与电脑在同一 WiFi 时，需要额外一步：把监听地址从 `127.0.0.1` 改成 `0.0.0.0`，并让 Windows 防火墙放行该端口。

```bash
# 方案 A：管理员已放行 5000（见下方命令），直接对外监听
python -m backend.dev --host 0.0.0.0 --port 5000 --serve-dist

# 方案 B：无管理员权限时，Flask 只监听本机，由 Node 代理对外（本仓库自带脚本）
python -m backend.dev --host 127.0.0.1 --port 5001 --serve-dist
node scripts/lan-proxy.mjs 5000 5001
```

放行端口（**管理员** PowerShell，执行一次即可）：

```powershell
New-NetFirewallRule -DisplayName "CampusBazaar 5000" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 5000 -Profile Any
```

手机浏览器打开 `http://<电脑局域网 IP>:5000`，例如 `http://192.168.1.105:5000`。查 IP：`ipconfig` 里的「无线局域网适配器 WLAN → IPv4 地址」。

注意事项：

- 前端请求用相对路径 `/api`，因此**单端口**即可，不需要额外代理或改 `baseURL`；
- 若手机打不开但电脑本地能开，先查防火墙规则，再确认路由器是否开启了「AP 隔离 / 访客网络」；
- 方案 B 的 Node 代理只做转发，不参与生产部署，`node scripts/lan-proxy.mjs` 需要 Node 18+。

## 5. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `端口 5000 被占用` | 换端口：`python -m backend.dev --port 5001`，同时改 `vite.config.js` 代理 |
| `数据库初始化异常` | 删除 `instance/campus.db` 与 `instance/.dev-secrets` 后重启，会重新迁移与灌数据 |
| 前端 401 循环跳登录 | 确认后端与前端同一 `localhost`/`127.0.0.1`；清掉 `localStorage` 中 `cb_token`/`cb_admin_token` |
| 验证码提示"过于频繁" | 发送限流 60 秒一次；换手机号或等待 |
| 管理员登录 429 | 连续失败 5 次锁定 15 分钟；等待或重启进程（本地缓存） |
| 商品图 404 | 未执行种子：`python -m backend.seed`；图片由种子生成到 `backend/static/uploads/demo/` |
| `npm install` 很慢 | 使用国内源：`npm config set registry https://registry.npmmirror.com` |
