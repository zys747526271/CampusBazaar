# 06 · 本地运行与测试指南

> 本文只提供**方法**，不替你执行。所有命令请你在自己的终端里按需运行。

## 路径 A：快速冒烟测试（推荐先做，无需数据库）

此模式使用 `TestingConfig`：**SQLite 内存库 + SimpleCache**，不需要安装 MySQL 和 Redis，用来确认服务能启动、路由能注册、健康检查与 API 概览页可用。

### A1. 建虚拟环境并安装依赖

```bash
cd /d/work/program/web/CampusBazaar

# 用便携 Python 创建虚拟环境（若已建过可跳过）
../tool/python-win/python.exe -m venv .venv

# 激活（Git Bash）
source .venv/Scripts/activate
# 若是 CMD/PowerShell，用： .venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

### A2. 以 testing 模式启动后端

```bash
# 从项目根目录执行，CAMPUS_CONFIG=testing 会启用 SQLite + SimpleCache
CAMPUS_CONFIG=testing python -m backend.app
```

看到类似 `Running on http://127.0.0.1:5000` 即启动成功。

### A3. 验证（在另一个终端）

```bash
# 健康检查，应返回 {"status":"ok",...}
curl http://127.0.0.1:5000/api/health

# API 概览页（浏览器打开）
# http://127.0.0.1:5000/
```

说明：
- testing 模式下注册 / 验证码等依赖 Redis 的接口仍可能报错（代码对 Redis 失败做了降级，验证码会打印到控制台），但**服务本身可以起、页面可以开**，足以做结构冒烟。
- 若启动即报 `ModuleNotFoundError`，回到 A1 确认依赖已装；若报 CRT/SSL 相关，参考文末排错。

## 路径 B：完整运行（MySQL + Redis）

### B1. 准备外部服务

1. 安装并启动 **MySQL**，创建数据库：
   ```sql
   CREATE DATABASE campus_bazaar DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
2. 安装并启动 **Redis**（默认端口 6379 即可）。

### B2. 配置环境变量

```bash
# 复制模板
cp .env.example .env
```

编辑 `.env`，至少填好：

```
SECRET_KEY=任意长随机字符串
JWT_SECRET_KEY=另一个长随机字符串
DATABASE_URL=mysql+pymysql://用户名:密码@localhost:3306/campus_bazaar
REDIS_URL=redis://localhost:6379/0
CAMPUS_CONFIG=development
ENCRYPTION_KEY=   # 可用 python backend/utils/miyao.py 生成后填入
```

> `.env` 已在 `.gitignore` 中，**不会被提交到 Git**。请勿把真实密钥写进任何源码文件。

### B3. 安装依赖并启动后端

```bash
cd /d/work/program/web/CampusBazaar
source .venv/Scripts/activate
pip install -r requirements.txt

# development 模式（读取 .env）
python -m backend.app
```

首次启动 `db.create_all()` 会自动建表。控制台若打印“数据库表创建失败”，通常是 `.env` 里的数据库连接信息不对或 MySQL 未启动。

### B4. 启动前端

```bash
cd /d/work/program/web/CampusBazaar/frontend
npm install
npm run dev
```

浏览器打开 `http://localhost:8080`。Vite 已配置把 `/api` 代理到 `http://localhost:5000`。

### B5. 基本功能自测清单

1. 打开前端首页，确认轮播/商品区能加载（商品列表可能为空，正常——无种子数据）。
2. 注册一个普通用户 → 登录 → 查看 `/api/auth/profile`。
3. 用 `POST /api/products` 发布商品，观察是否成功（注意：当前前后端字段有已知错配，见 `05-已知问题与路线图.md`，发布可能失败属预期）。
4. 打开 `http://localhost:5000/` 查看 API 概览页，核对路由清单。

## 常见问题排错

- **后端起不来，报 `No module named backend`**：确认是在项目根目录执行 `python -m backend.app`，而不是在 `backend/` 目录内。
- **Git Bash 里 `source .venv/Scripts/activate` 报错**：改用 `./.venv/Scripts/activate`；或直接用 `.venv/Scripts/python.exe` 代替 `python`。
- **pip 安装 SSL 证书报错**：可临时用可信镜像源，例如 `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`。
- **`CAMPUS_CONFIG=testing` 不生效**：确认是通过 `python -m backend.app` 启动（配置在 `create_app()` 里读取环境变量），且环境变量与命令在同一行或已 export。
- **前端 `npm install` 慢或失败**：配置国内镜像 `npm config set registry https://registry.npmmirror.com` 后重试。
- **登录相关接口 500**：多为 Redis 未启动或字段错配；testing 模式下部分接口不可用属预期。
